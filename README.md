# La Tramoya - Plataforma de Gestión y Memoria del Carnaval de Cádiz

Sistema destinado a la digitalización del Concurso Oficial de Agrupaciones Carnavalescas (COAC) y la preservación de su archivo histórico.

---

## 🎯 Objetivos del Proyecto

- **Gestión del Concurso (Back-Office):** Tramitación digital de inscripciones, sorteos, sesiones del Gran Teatro Falla, puntuaciones del jurado y fallos oficiales.
- **Memoria Histórica (Front-Office):** Archivo abierto y consulta de agrupaciones, autorías, componentes, repertorios y palmarés a lo largo de las décadas.
- **Sostenibilidad:** Código abierto, modular y diseñado con estándares que garanticen su mantenimiento a largo plazo.

---

## 🛠️ Stack Tecnológico

- **Lenguaje:** Java 21 LTS
- **Backend:** Spring Boot (Spring Data JPA, Spring Security)
- **Frontend:** Vaadin
- **Gestión de dependencias:** Apache Maven
- **Base de datos:** PostgreSQL
- **Infraestructura Cloud:** AWS
